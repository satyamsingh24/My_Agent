My_AGENT

Created by Satyam Singh Bhadoriya

ATS CV builder that runs in your browser from your own computer. This page is the project page only — the app itself runs locally.

  • Upload a CV, paste a job description, generate an ATS-friendly CV
  • Build a CV from scratch with an optional profile photo
  • Generate a short cold email for HR referrals from any CV
  • Download as PDF, DOCX, or XLSX
git clone https://github.com/satyamsingh24/My_Agent.git cd My_Agent python -m pip install -r requirements.txt python -m streamlit run app.py

App opens at http://localhost:6932 · PIN: 6932
